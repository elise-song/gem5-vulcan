    mem-cache: Add cache partitioning by process ID
    
    - The context ID (process ID) is added to the address for process isolation in the cache.
    - This is meant for a cache without prefetching or snooping.
    - To pass the context ID to the cache, the TaggedTypes::KeyType struct is changed to a class that has two constructors. The original struct design is retained with physical addr and isSecure parameters. Another constructor is added with a packet parameter which contains the virtual address and context ID. When possible, the packet constructor is used instead.
