    mem-cache: Update cache to employ VIPT instead of PIPT
    
    - Changed the TaggedSetAssociative indexing policy to use index derived from virtual address. Tag is still derived from physical address.
    - This is meant for a cache without prefetching or snooping. If the request doesn't have a virtual address, the physical address is used as default.
